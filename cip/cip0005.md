## Summary

Present Brendan / Olivetti faces as an **image** reconstruction on the
CIP-0002 host. This is GPy `image_show`: reshape a `Y` row to
`(height, width)`, transpose / Fortran order as the demo specifies,
write the image data on modify.

## Motivation

`brendan_faces` and `olivetti_faces` are the remaining GPy `visualize`
demos people actually run. They still call `image_show` and `lvm`. An
image pane is the last Visualise/Modify shape the stick/doodle/oil
host does not yet have.

Do this after CIP-0004 (vector). The host is the same; only the view
changes. Faces are slower to load and easier to get reshape-wrong
(`order='F'`, `transpose=True` on Brendan).

## Detailed Description

### View: `ImageView`

- **Visualise:** Bokeh `image` (greyscale). Freeze the plot box to the
  pixel grid. Do not autoscale. Match GPy `image_show` flags:
  `dimensions`, `transpose`, `order` (`C`/`F`), `invert`, optional
  `scale` / preset mean and std.
- **Modify:** write the ColumnDataSource (or `image` CDS) only. Do not
  rebuild the figure.
- Mosaic of several images in one vector (GPy `num_images`) is out of
  scope unless a demo needs it.

### Host and demo

`face_explorer` builds `ImageView` and calls `latent_explorer`. First
demo: Brendan faces, `dimensions=(20, 28)`, `transpose=True`,
`order='F'`, as in `GPy.examples.dimensionality_reduction.brendan_faces`.
Olivetti is the same view with different reshape.

`examples/faces.py` is the `servable()` entry.

Q=2 Bayesian GPLVM with inducing points, as in the GPy example. Do not
inflate Q to “play with ARD” (the doodle 6-D attempt).

### What this is not

Doodle strokes (CIP-0003). Oil vector (CIP-0004). Hierarchical skeleton
leaves (CIP-0006).

## Implementation Plan

1. `ImageView` reshape tests (C vs F, transpose) without GPy.
2. Brendan demo + `examples/faces.py`.
3. README. Optional Olivetti wrapper with the same view.
4. GPy examples keep `visualize` until this works (GPy CIP-000B).

## Backward Compatibility

Existing explorers unchanged. Image flags must be explicit so Brendan
does not silently render as a 28×20 transpose of Olivetti.

## Testing Strategy

Reshape unit tests. Explorer construction `importorskip`s Panel / GPy /
pods. Manual serve after Optimize; check the face is upright.
