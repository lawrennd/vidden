## Summary

Stand up `vidden` as a Python package and move the Panel stick-man
latent explorer out of GPy. GPy CIP-000B remains only as the
deprecation of `GPy.plotting.matplot_dep.visualize`.

## Motivation

The explorer was developed on GPy branch
`cip000B-modern-latent-visualize`. Interactive viewers do not belong in
the inference library: they pulled Panel into GPy's example tree, and
the matplotlib path they replace is already broken. A separate package
lets GPy deprecate `visualize.py` without hosting a browser UI.

## Detailed Description

### Package form

Setuptools `src/` layout, same as bridle. Core dependency: numpy.
Optional extras: `explore` (HoloViews, Panel, Bokeh) and `gpy` (GPy,
pods) for the stick demo.

Public import path: `vidden.explore`.

### What moves from GPy

`GPy/examples/stick_explorer_spike.py` and
`GPy/testing/test_stick_explorer_spike.py`. The spike already follows
MATLAB `stickVisualise` / `stickModify` (Bokeh `ColumnDataSource` writes,
frozen cubic limits, click-to-track, zeros-and-persist latent position,
Bokeh `context_menu` for the histogram x-axis).

Duck-type GPy instead of importing `VariationalPosterior`: use `X.mean`
only when it is an array, not a method.

### What stays in GPy

Static plotting. Demo *data* loaders (`pods`). The old `visualize.py`
file, with a `DeprecationWarning` pointing here, until examples stop
importing it.

### Serve path

`panel serve examples/stick.py --show`. The library module must not
call `servable()` on import.

## Implementation Plan

1. **Package skeleton**: `pyproject.toml`, `src/vidden`, LICENSE, README,
   tenets, requirements.
2. **Transfer the spike** into `vidden.explore` and tests.
3. **GPy deprecation**: warning on `visualize` import; spike file becomes
   a stub pointing here.

## Backward Compatibility

New package. GPy callers of `visualize.lvm` keep working with a
warning. `GPy.examples.stick_explorer_spike` will tell people to import
`vidden.explore`.

## Testing Strategy

Pytest in `tests/`. Geometry tests need numpy. Explorer construction
and GPLVM tests `importorskip` GPy / Panel / Bokeh. No live browser
driver in CI.
