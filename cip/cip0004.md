## Summary

Present the oil-flow GPLVM the same way as stick and doodle: a
reconstruction **view** on the CIP-0002 **host**. The reconstruction is
GPy `vector_show` — a 12-D observation as a line of index against
value — not a new latent plot.

GPy `examples.dimensionality_reduction.bgplvm_oil` still calls
`visualize.vector_show` and `lvm_dimselect`. This CIP is how we show
that space in vidden.

## Motivation

Oil is the teaching example for a Bayesian GPLVM with labels and more
than two latent axes. The reconstruction is a short vector, so it is
the cheapest remaining `visualize` pane. Porting it proves
`latent_explorer(model, view)` on a 1-D curve before we take on images.

## Detailed Description

### View: `VectorView`

MATLAB Visualise / Modify.

- **Visualise:** Bokeh line, x = `0 .. D-1`, y = the packed row. Freeze
  y-limits from the training set (or a stated pad around min/max of
  `Y`). Do not autoscale on modify.
- **Modify:** write `ColumnDataSource.data` only.

No image reshape, no bones. `D` is `Y.shape[1]` (12 for oil).

### Host and demo

`oil_explorer` builds `VectorView` and calls `latent_explorer`. Default
data is `pods.datasets.oil()` as in `bgplvm_oil` (subset `N`, `Q=7`,
inducing points, ARD RBF). Labels colour the latent scatter if the
model carries `data_labels`.

`examples/oil.py` is the `servable()` entry:
`panel serve examples/oil.py --show`.

Pointer, click-to-track, zeros-and-persist, ARD bars, Optimize: unchanged.

### What this is not

Hierarchical GP-LVM (CIP-0006). Face images (CIP-0005). SSGPLVM as a
separate demo — same view, later if needed.

## Implementation Plan

1. `VectorView` with frozen y-limits; tests for modify and `servable()`.
2. `load_oil_model` / `oil_explorer` / `examples/oil.py`.
3. README section. GPy `bgplvm_oil` can keep `visualize` until this
   demo works; pointing that example at vidden is GPy CIP-000B, not
   this CIP.

## Backward Compatibility

`stick_explorer` and `doodle_explorer` unchanged. No Referia.
